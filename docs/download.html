Requirements

  • Minecraft26.3Java Edition
  • Fabric Loader0.20+Install it for 26.3 with the Fabric installer
  • Fabric API0.165.2+Built for 26.3, goes in the mods folder
  • GeckoLib5.5.7Animated models of bosses and creatures
  • Java25Bundled with the official launcher

Installing

  1. Install Fabric Loader for Minecraft 26.3.
  2. Download matriochka-0.1.0.jar from the GitHub releases.
  3. Put it in your mods folder with Fabric API and GeckoLib.
  4. Launch the Fabric profile and create a new world. The Artisan's Scroll is waiting in your inventory.

Lunar Client

Matriochka is built on Fabric so that it can run on Lunar Client, whose mod loading relies on Fabric. Support for Minecraft 26.3 together with GeckoLib is still being confirmed there: if the mod does not load, play it with the official launcher or Prism Launcher on a Fabric profile in the meantime.
