Télécharger

Version 0.1.0 pour Minecraft 26.3 sous Fabric. Installe-la côté client pour jouer en solo, et sur le serveur et chaque client pour jouer ensemble.

Prérequis

  • Minecraft26.3Édition Java
  • Fabric Loader0.20+À installer pour la 26.3 avec l'installeur Fabric
  • Fabric API0.165.2+Pour la 26.3, dans le dossier mods
  • GeckoLib5.5.7Modèles animés des boss et créatures
  • Java25Fourni avec le launcher officiel

Installation

  1. Installe Fabric Loader pour Minecraft 26.3.
  2. Télécharge matriochka-0.1.0.jar depuis les versions GitHub.
  3. Place-le dans ton dossier mods avec Fabric API et GeckoLib.
  4. Lance le profil Fabric et crée un nouveau monde. Le Parchemin de l'artisan t'attend dans l'inventaire.

Lunar Client

Matriochka repose sur Fabric pour pouvoir tourner sur Lunar Client, dont le chargement de mods s'appuie sur Fabric. La prise en charge de Minecraft 26.3 avec GeckoLib y est encore en cours de vérification : si le mod ne se charge pas, joue en attendant avec le launcher officiel ou Prism Launcher sur un profil Fabric.
