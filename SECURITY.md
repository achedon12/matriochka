# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

If you find a way to crash servers, corrupt worlds, or let a client run actions it should not (packet abuse, item duplication, permission bypass), please **do not open a public issue**.

Report it privately with [GitHub's private vulnerability reporting](https://github.com/achedon12/matriochka/security/advisories/new). Include the mod version, the steps to reproduce, and what you expected to happen. You should get an answer within a week, and credit in the changelog once a fix ships if you want it.
